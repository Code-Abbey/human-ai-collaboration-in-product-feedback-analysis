# Project plan

The concept proposes six months of work. These are project stages rather than fixed calendar dates.

| Month | Main work | Expected result |
|---|---|---|
| 1 | Review the literature and agree the scope, dataset and evaluation design with the supervisor. | A clear research plan and relevant references. |
| 2 | Select and clean the app reviews; design the classification, theme, summary and action-generation steps. | A manageable dataset and pipeline design. |
| 3 | Build the dashboard and human refinement features. | A working prototype. |
| 4 | Run a small pilot and improve the interface, workflow and scoring guidance. | A tested study procedure. |
| 5 | Compare manual, AI-only and Human-in-the-Loop analysis; collect expert ratings and comments. | Reports and evaluation data. |
| 6 | Analyse the results, discuss limitations and complete the thesis. | The final written thesis. |

Dataset preparation has started. The [progress page](status.md) records completed work separately from these planned stages.
