# Why the datasets fit the project

The [concept](concept.md) proposes analysing written reviews from a selected product domain. The current proposal is to select one app. The number of reviews has not been fixed and may exceed the initial estimate in the concept. The reviews must contain enough useful feedback to identify common themes, write summaries and suggest app improvements. Existing labels or summaries are not required.

| Part of the project | What the dataset provides |
|---|---|
| Manual analysis | Reviews that a person can read and group. |
| AI analysis | The same review text as input to the AI. |
| Human refinements | Original reviews that a person can use to check, edit, merge or split AI-generated outputs. |
| Expert report evaluation | Evidence for rating clarity, usefulness, actionability, relevance, completeness and overall quality. |

Participants' perceived workload and the types of changes they make will be recorded where feasible. These measures do not need to be included in the original dataset.

## Proposed choice

**Kahoot!** has a substantial source review collection from which study and practice samples could be selected. The main task is selecting useful feedback from the many short or general comments.

**Spotify** is a suitable alternative with 1,000 reviews. The initial examples include problems with downloads, playback and the interface.

**Zoom** is another option. The examples checked so far include login problems, meeting issues, and problems with sound or video.

The Spotify and Zoom source files inspected during the preliminary feasibility checks do not include review dates. This limits analysis of changes over time, but does not prevent the planned report comparison.

**RARE** contains original and rewritten reviews. The related paper provides useful background, but the dataset is not needed for the main study.

## Next decision

The researcher will first select and download a dataset. Inspection and a small trial will then help determine the selection rules and a suitable sample size. The final review groups will be prepared after these decisions. The available data support the proposed work. The study will compare the three approaches using the submitted research questions.
