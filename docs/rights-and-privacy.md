# Data permissions and privacy

The datasets come from published research sources. The planned use is non-commercial thesis research.

| Dataset | Source licence |
|---|---|
| GenAI-EdSent / Kahoot! | CC BY-NC 4.0 |
| Top 15 / Spotify and Zoom | CC BY 4.0 in the metadata; the description also mentions non-commercial use |
| RARE | CC BY 4.0 |

The dataset creators and related papers are credited in the [references](../references/README.md). The licences require users to credit the creators. CC BY-NC also restricts use to non-commercial purposes. Personal information still needs to be handled carefully, even when a dataset has an open licence.

Raw reviews are kept locally and are not uploaded to the public repository. The repository provides download links, scripts and summary findings.

The selected study data will exclude usernames, profile images and other unnecessary personal details. Review text will also be checked for names, contact details and sensitive information. Automatic checks alone cannot remove every personal detail.

Storage, access and deletion arrangements will be agreed before the participant study. Review text will be checked for personal information before any proposed use with an external AI service.
